# Running the application
## Double-click
Double click 'run.bat' in the project root

## From the terminal
In the project root, run:

**PowerShell:**
`.\run.bat`

**Command Prompt:**
`run.bat`

## After startup
The app starts on http://localhost:8080 with example data from `data.sql`.
The database is in memory, anything you create is lost when the app stops.

All endpoints are documented in [endpoints.md](endpoints.md), including example 
`curl` requests you can copy and run in a separate terminal once the app has started.# assignment_Spring-Data-JPA
